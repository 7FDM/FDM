# عُهدة — نسخة عرض إدارية محلية

افتح `site/index.html` مباشرة في المتصفح. اختر دور أمين العهد لتجربة الإعارة والإرجاع والجرد، ودور المشرف للوحة التحكم. البيانات افتراضية ومحصورة في أصول مكتبية. لا تدخل بيانات حقيقية أو عسكرية أو شخصية. لا تُرسل أي طلبات شبكة من التطبيق. سجلات المتصفح قابلة للتغيير وليست سجلاً تدقيقياً محصناً. الأدوار محاكاة للواجهة فقط وليست مصادقة أو صلاحيات أمنية حقيقية.

## Netlify
ارفع مجلد `site` فقط باستخدام https://app.netlify.com/drop أو اربط مستودعاً خاصاً يحتوي المشروع (publish: site). لا ترفع بيانات حساسة أو مفاتيح. ترويسة noindex لا تمنع الوصول العام. فعّل حماية الوصول قبل أي استخدام غير تجريبي. 

## الربط السحابي
لم تُنشأ أي موارد سحابية أو تُعدّل قاعدة البيانات الحالية. `integrations/PLAN.md` يوضح حدود ومسؤوليات الخدمات المطلوبة. النسخة الحالية محلية بالكامل ولا تدّعي وجود مصادقة أو تخزين أو ذكاء اصطناعي سحابي.

## الإنتاج
لا يُستخدم هذا النموذج في إدارة عمليات عسكرية فعلية. يلزم اعتماد أمني مستقل وتصنيف البيانات، وموافقة جهة الاختصاص على الاستضافة ومناطق تخزين ومعالجة البيانات، واختبار المصادقة والصلاحيات والتدقيق والنسخ الاحتياطية قبل أي استخدام حقيقي.
