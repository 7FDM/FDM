# سِنان — إدارة الأصول الإدارية

الموقع الرئيسي: https://fdm1.netlify.app

واجهة عربية تجريبية للأصول المكتبية، بهوية وشعار مخصصين. تشمل لوحة التحكم، بطاقات الأصول، محاكاة الإعارة والإرجاع، الجرد، التنبيهات وسجل النشاط المحلي. لا تدخل بيانات شخصية أو عسكرية حقيقية. اختيار الأدوار محاكاة وليس مصادقة؛ السجل المحلي قابل للتعديل وليس محصناً.

## التشغيل
مجلد النشر: `site`. الاستضافة على Netlify والكود على GitHub. تبقى قاعدة Supabase الخاصة بالنسخة المكتبية قائمة، ولكن المصادقة والربط السحابي بالواجهة غير مكتملين. لا توجد خدمات Cloudflare أو AI في نطاق النسخة الحالية. لا توجد ترقية مدفوعة مطلوبة لهذه الواجهة.

لا يُعتمد النظام كنسخة إنتاجية حساسة. يلزم اختبار مستقل للصلاحيات والمصادقة وحماية السجلات.
