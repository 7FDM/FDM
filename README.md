# منظومة عُهدة

الموقع الرئيسي: https://fdm1.netlify.app

نموذج عرض عربي لمستودعات السلاح باستخدام عينات تدريبية خاملة وبيانات وهمية فقط. يعرض لوحة التحكم وبطاقات العينات ومحاكاة الجرد والحركات المحلية. لا تدخل بيانات أسلحة أو بيانات عسكرية أو شخصية حقيقية. الأدوار الظاهرة (مشرف المستودع وأمين المستودع) للمحاكاة وليست مصادقة، والسجل المحلي غير محصن.

## التشغيل
مجلد النشر: `site`. GitHub وNetlify. قاعدة Supabase الحالية لم تتغير، والربط السحابي غير مكتمل. Cloudflare والذكاء الاصطناعي خارج نطاق المشروع. لا تستخدم النموذج لإدارة مستودع حقيقي.
